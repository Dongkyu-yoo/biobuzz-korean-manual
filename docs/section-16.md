# 16 Glossary {#s-16}

다음 정의와 용어는 FIRST Tech Challenge Game BIOBUZZ에서 사용됩니다. 정의된 용어는 Manual 전체에서 ALL CAPITAL LETTERS로 표시됩니다(예: ALLIANCE). Competition Rule은 문장에 적힌 일반적인 의미 그대로 해석합니다. 어떤 단어에 Game Definition이 주어지지 않았다면 일반적인 대화에서 사용하는 의미를 적용하십시오.
